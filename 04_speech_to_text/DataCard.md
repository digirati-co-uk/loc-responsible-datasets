# Speech to Text with entities Datacard

## Dataset Description

### Dataset Summary

The speech to text dataset is a collection of transcripts of interview audio files with additional entity annotations which mark up the interviews with:

* PERSON 
* ORG 
* GPE 
* LOC 
* FAC 
* NORP 
* DATE 
* EVENT
* QUANTITY

entities, following the Ontonotes standard definition of these terms. 

The purpose of the dataset is to provide both good quality ground truth for speech to text transcription, and also provide data for training and evaluating entity recognition (in general), and tools for the identification of PII (personally identifying information) in the audio, in particular.

### Supported Tasks

* Speech to text
* Entity recognition

### Languages

* English
